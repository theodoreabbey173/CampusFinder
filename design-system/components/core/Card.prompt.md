The base surface used everywhere — white background, subtle border, soft shadow, 14px radius.

```jsx
<Card elevation="md">…</Card>
<Card accent="lost">Lost-item content with an orange stripe</Card>
```

`accent` adds a colored left stripe (the pattern used on Lost/Found list rows). Set `padded={false}` when the child manages its own spacing (e.g. media at the top).
